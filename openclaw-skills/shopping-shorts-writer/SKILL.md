# 쇼핑 쇼츠 대본 작가

## When to Use This Skill
- "이 상품으로 40초 대본 만들어줘: [상품명]"
- 파이프라인 Step 2로 호출될 때

## 절대 금지 단어 (하나라도 포함되면 즉시 재작성)
```
쿠팡, 할인, 특가, 세일, 링크, 클릭, 구매, 프로필, 설명란
숫자+원 (예: 19,900원, 3만원)
```

## 대본 규칙
| 규칙 | 값 |
|------|-----|
| 총 길이 | 40초 분량 (130~160자) |
| 말투 | ~요 체 (자연스러운 체험담) |
| 상품명 | 전체 대본에서 **딱 1회**만 |
| 마지막 5초 | "관심 있는 분은 댓글에 'OO' 한 글자만 남겨주세요" |

## Instructions

### 1. 대본 생성
주어진 상품 정보로 아래 5구간 타임라인에 맞게 작성하세요:

**[0:00~0:03] 후킹 — 3초**
강렬한 한 문장. 공감/호기심. 상품 언급 절대 없음.
패턴 A (단정형): "이거 진짜 안 써본 사람은 있어도 한 번만 쓴 사람은 없어요."
패턴 B (후회형): "이걸 진작 알았으면 그 고생을 안 했을 텐데요."
패턴 C (질문형): "하루 종일 화면 보는 분, 이거 한 번만 읽어보세요."

**[0:03~0:10] 불편 공감 — 7초**
구체적인 일상 불편 상황. before 장면.
"아무리 발라도 오후만 되면 당기고, 파운데이션은 갈라지고..."

**[0:10~0:28] 체험 스토리 — 18초 (핵심)**
상품명 **1회** + 감각적 before→after 묘사.
"그러다 ○○ 수분 크림을 써봤는데, 바르자마자 흡수가 다르더라고요..."
핵심 표현: "딱 잡는 순간 느껴요", "바르자마자 흡수가 다르더라고요", "쓰고 나서 좀 놀랐어요"

**[0:28~0:35] 감성 마무리 — 7초**
진심 추천. 강요 없이.
"이건 주변 사람들한테 다 알려주고 다녔어요."

**[0:35~0:40] 키워드 유도 — 5초**
"관심 있는 분은 댓글에 '[키워드]' 한 글자만 남겨주세요."

### 2. 자체 검수 (반드시 수행)

#### 하드 체크 (통과 못하면 즉시 재작성):
- [ ] 금지어 0개
- [ ] 상품명 정확히 1회
- [ ] 글자수 130~160자
- [ ] ~요 체 통일 (습니다체 없음)

#### 소프트 체크 (1~10점 평가):
- 자연스러움: 실제 사람이 말하는 것처럼?
- 후킹 강도: 첫 3초에 시선을 끄는 힘?
- 체험 구체성: before→after가 감각적으로 명확?

**종합 점수 = (자연스러움 + 후킹 + 구체성) / 3**
**7점 미만이면 재생성** (최대 3회)
3회 모두 7점 미만이면 가장 높은 점수의 대본을 사용.

### 3. 결과 출력
```
제목: [15자 내, 호기심 유발]
대본:
[0:00~0:03] [후킹 텍스트]
[0:03~0:10] [공감 텍스트]
[0:10~0:28] [체험 텍스트]
[0:28~0:35] [마무리 텍스트]
[0:35~0:40] [키워드 유도]

글자수: [N]자
검수 점수: [N]/10 (자연스러움[N] + 후킹[N] + 구체성[N])
댓글 키워드: [1~2글자]
검색 키워드: [키워드1, 키워드2, 키워드3]

YouTube 제목: [제목]
YouTube 설명: [2~3줄 설명]
Instagram 캡션: [해시태그 포함]
```
