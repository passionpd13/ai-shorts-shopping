인포크 + 쿠팡 파트너스 — 수익화 설정 가이드

6개 Part, 302줄. 설정 완료 시 "댓글 하나 → 커미션 수익" 자동화 완성

시청자가 경험하는 흐름

릴스 시청 → 댓글 "청소" → 인포크 매니저 감지 → DM 자동 발송 → 인포크링크 클릭 → 쿠팡 이동 → 구매 → 3%
1
쿠팡 파트너스 가입 + API 키

partners.coupang.com 가입 → 계좌 등록 → 도구 → API → 키 생성. 가입 즉시 링크 생성 가능, 최종 승인은 첫 매출 15만원 후.

→ COUPANG_ACCESS_KEY, COUPANG_SECRET_KEY, COUPANG_PARTNER_ID

2
인포크 가입 + 매니저 플랜 구독

inpock.co.kr 가입 → Instagram 비즈니스 계정 연결 → 매니저 플랜(월 18,000원~) 선택. DM 자동화는 매니저 플랜에서만 가능. 프로플랜(5,900원)은 링크만 가능.

3
인포크링크 페이지 + 쿠팡 연동

인포크링크 페이지 생성 → 파트너스 탭에서 쿠팡 연동 (API 키 입력) → 상품별 링크 블록 추가. Instagram 프로필 웹사이트에 인포크링크 URL 연결.

→ 프로필: inpock.co.kr/내계정이름

4
인포크 매니저 — 게시물별 DM 자동화

릴스 업로드 후 → 인포크매니저에서 해당 게시물 선택 → 키워드 설정 → 팔로워/비팔로워 메시지 작성 → CTA 버튼에 인포크링크 URL → 활성화. 게시물마다 반복.
